# O Cronista — Bot

O Cronista is the Discord-facing submodule: it manages Session lifecycle via slash commands, records voice audio, and generates Artifacts (Crônica + Session Notes) from Transcripts.

## Language

**Session**:
A single RPG gathering. Starts when the Master runs `/join`. Ends with `/stop` or is abandoned with `/discard`. Tolerates multiple voice channel reconnections — recording accumulates across them.
_Avoid_: Meeting, recording, game

**Crônica**:
A narrative chronicle of a Session written for the players — what their characters saw, experienced, and discovered. Generated by the Cronista Worker from a Transcript.
_Avoid_: Cronic, chronicle, player notes, summary

**Session Notes**:
The Master's operational document for a Session — what was revealed (and what wasn't), NPC dialogue, plot threads pulled, and state changes. Private to the Master.
_Avoid_: GM notes, master notes, recap

**Artifact**:
A generated document produced from a Session's Transcript — either a Crônica or Session Notes.
_Avoid_: Output, report, document, export

**Transcript**:
The raw text output of the Transcription Service for a Session. The source material for Artifact generation.
_Avoid_: Transcription (verb/process), log, text dump

## Responsibilities

- Accept `/join`, `/stop`, `/discard` slash commands from Discord
- Record each speaker to a separate `.wav` file during a Session
- Transcribe recordings via faster-whisper (PT-BR) — inline for MVP; delegated to `cronista/transcriber` later
- Dispatch artifact generation task to Cronista Worker (future)
- Read from Wiki via MCP for player Q&A and Session Bootstrap (future)

## Structure

```
core/           # business logic — no Discord awareness
  recording/    # VoiceSession, SpeakerTrack, AudioSink, session lifecycle
  transcription/ # Segment, Transcript, faster-whisper wrapper
entrypoints/    # Discord interface layer — thin, delegates to core
  bot.py        # bootstrap: loads cogs, starts client
  cogs/
    voice.py    # /join, /stop, /discard commands
config.py       # Pydantic Settings (BOT_TOKEN, SERVER_ID)
logging_config.py
```
